# Quiz answer key — GitOps + policy

Use only after attempting the quiz questions.

1. Git (the declared manifests/config).
2. Pull: agent in-cluster fetches git; push: CI/CD applies kubectl/helm from outside.
3. Stops unsafe desired state from becoming live; faster feedback.
4. Kyverno, OPA/Gatekeeper, Conftest, etc.
5. Cluster drifted from git; sync/reconcile missing or paused.
6. Non-reproducible deploys; surprise supply-chain updates.
