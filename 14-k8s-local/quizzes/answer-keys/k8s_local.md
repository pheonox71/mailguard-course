# Quiz answer key — K8s local

Use only after attempting the quiz questions.

1. Deployment manages Pod replicas/rollouts; Service provides a stable network endpoint to Pods.
2. Whether the Pod receives Service traffic.
3. Scheduler placement and noisy-neighbor protection; predictable capacity.
4. You operate the control plane locally vs provider-managed control plane/SLA.
5. Kubelet restarts the container repeatedly.
6. Node pressure / OOMKills; other workloads may be evicted.
