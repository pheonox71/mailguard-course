# Quiz answer key — Phish Lite

Use only after attempting the quiz questions.

1. Consent and trust — avoid tricking people outside an approved program.
2. Real passwords / credentials / session tokens.
3. Report rate (or time-to-report).
4. Measures healthy reporting behavior, not only avoidance of clicks.
5. Credential capture risk; unethical and potentially unlawful.
6. Public shaming harms culture; use private coaching aggregates.
