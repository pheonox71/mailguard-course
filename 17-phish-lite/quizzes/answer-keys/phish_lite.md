# Quiz answer key — Phish Lite

Use only after attempting the quiz questions.

1. Consent and trust — avoid tricking people outside an approved program; unlabeled sims teach distrust of IT and can be unlawful.
2. Real passwords / credentials / session tokens — harvesting secrets is abuse, not education, and creates breach liability.
3. Report rate (or time-to-report) — rewards the behavior you want when real phish arrives.
4. Measures healthy reporting behavior under time pressure, not only avoidance of clicks.
5. Credential capture risk; unethical and potentially unlawful — stop, delete any captured secrets, redesign without password fields.
6. Public shaming harms culture; use private coaching and aggregates instead.
