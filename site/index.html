How students move through a module

Every module with assets follows the same required path. Save finished worksheets and filled quiz PDFs under my-work/ in the course repo.

  1. Read on-site — open the module page and work through the rendered reading (with figures when present).
  2. Download the worksheet and save finished answers under my-work/worksheets/.
  3. Download the tests (when present) and implement until they pass.
  4. Download the required quiz (PDF), complete it, then check the separate answer key. Answer keys are never inside the quiz PDF.
