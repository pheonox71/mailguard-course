How students move through a module

Read the topic, work the worksheet, implement against the tests. Download fillable quiz PDFs when you want a self-check — save finished work under my-work/ in the course repo.

  1. Read the module reading for the concept map.
  2. Download the worksheet and save finished answers under my-work/worksheets/.
  3. Download the tests and implement until they pass. Quiz PDFs are optional self-checks.
