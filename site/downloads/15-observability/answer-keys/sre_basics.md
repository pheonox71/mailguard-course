# Quiz answer key — sre basics

Use only after attempting the quiz questions.

1. Service Level Indicator; Service Level Objective; Service Level Agreement: an external contract with consequences (refunds or credits) if missed. It is usually **looser** than the internal SLO. Teams set the SLO tighter so they get warned before they breach the SLA.
2. Quantifies allowed unreliability; guides when to invest in reliability vs features.
3. e.g. “lines of Go written” or raw request count without success criteria.
4. Focus on systems/process fixes, not punishing individuals.
