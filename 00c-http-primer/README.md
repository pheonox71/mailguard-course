# 00c — HTTP primer

Short, read-only primer before identity and API modules that speak HTTP. Work through the on-site reading, then mark the module complete.

**Language / tooling:** HTTP/1.1 concepts · status codes · headers · cookies · CORS · TLS

## What this teaches

- Name common methods and what “safe” vs “idempotent” means in practice
- Read status codes and key headers without guessing
- Explain cookies, CORS, and TLS at a literacy level used by OIDC and FastAPI labs

## Workflow

1. **Reading** — `readings/http_primer.md` (also on the course site)
2. Try the tiny hands-on example
3. Mark this primer complete in the site progress UI, then continue

This module has **no** assignments, quizzes, tests, or download packs.

## Layout

| Path | Role |
|------|------|
| `readings/` | Primer reading with official doc links |

## Done when

- You can explain why HTTP literacy shows up before OIDC and the MailGuard API
- The tiny example makes sense (curl against a public or local URL)
- The primer is marked complete in the site progress UI
