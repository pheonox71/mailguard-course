# Assignments (blank sheets)

Blank assignment sheets for every graded topic are already here. Open the matching file and answer in place — no copying from module folders or site downloads.

Naming: `<module-id>-<topic>.md`  
Example: `01-challenge-gym-totp_verify.md`

Module `assignments/` folders and site downloads remain available as reference copies of the same blanks. Leave those unchanged; write answers only under `my-work/assignments/`.
