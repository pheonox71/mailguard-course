# My work

Keep finished student work here in the course repo — not in a separate git fork, and not in the website UI.

Blank fillable copies are **already here**. Open them and answer in place — no need to copy files from each module or from site downloads.

| Folder | Put here |
|--------|----------|
| [`assignments/`](./assignments/) | Blank assignment sheets (pre-populated). Fill answers directly in these files. |
| [`quizzes/`](./quizzes/) | Blank fillable quiz PDFs (pre-populated). Fill answers in place. |

Do not edit answers into the blank `assignments/` or `quizzes/` files under each module (those stay as course sources / site downloads). Leave kata stubs in place until you implement them; keep your written answers in this tree.

Answer keys stay on the course site (separate downloads) and are **not** stored under `my-work/`.
