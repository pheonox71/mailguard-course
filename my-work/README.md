# My work

Keep finished student work here in the course repo — not in a separate git fork, and not in the website UI.

| Folder | Put here |
|--------|----------|
| [`assignments/`](./assignments/) | Completed assignment answers (copy or rename from each module’s `assignments/` downloads) |
| [`quizzes/`](./quizzes/) | Filled quiz PDFs downloaded from the course site |

Do not edit answers into the blank `assignments/` or `quizzes/` files under each module. Leave kata stubs in place until you implement them; keep your written answers in this tree.
