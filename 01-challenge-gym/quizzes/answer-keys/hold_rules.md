# Quiz answer key — hold rules

Use only after attempting the quiz questions.

1. Hold lets humans review borderline mail without blocking all business flow; hard-reject-only causes false-positive outages and workarounds that bypass DLP.
2. One clear outcome per message; partial multi-rule apply makes “what happened?” un-auditable and order ambiguous.
3. Keep the engine interview-explainable and within a short challenge budget; no mini-language to maintain.
4. Different first match → different action; operators must treat list order as intentional policy, not incidental.
5. **Hold** — Rule 1 matches first; Rule 2 never runs.
6. Spec drift: green-looking code that fails the real kata (or ship behavior nobody agreed on). Tests encode allow/hold/reject edge cases.
