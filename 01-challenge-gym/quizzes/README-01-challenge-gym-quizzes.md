# Challenge Gym — quizzes / self-checks

Short checks **after** each kata’s reading (and before or alongside the worksheet). They are for self-assessment — not graded, not proctored.

**Authorship:** AI-generated. Download fillable quiz PDFs from the course site and save completed copies under [`../../my-work/quizzes/`](../../my-work/quizzes/).

## Pattern (reuse in later modules)

For each topic that has a reading:

1. Ship `quizzes/<topic>.md` next to that module’s readings/worksheets.
2. Keep **5–8** items: mix recall, “why,” and one tiny scenario.
3. Keep answer keys in separate documents under `quizzes/answer-keys/` (not in the downloadable quiz PDF).
4. Link the quiz from the module README and from the reading’s end (“Self-check”).
5. Do **not** put office-hours / “ask for help” FAQ here — this course is self-serve.

Suggested filenames later: `07-mailguard-api/quizzes/…`, `02-mailguard-mfa/quizzes/…`, mirroring the reading slug.
