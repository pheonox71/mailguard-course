# Reference solutions

Completed implementations for each kata. **Do not import these from tests or from `katas/`.**

Peek only after you have:

1. Read the assignment and answered the questions in writing
2. Read the tests
3. Attempted the stub yourself
4. Gotten stuck for a meaningful stretch

To check a solution against the suite without spoiling the habit of implementing:

```bash
# from 01-challenge-gym/, with venv active
cp solutions/totp_verify.py katas/totp_verify.py
pytest tests/test_totp_verify.py -q
# then restore your work from git / undo the copy
```

Or compare side-by-side and keep writing in `katas/`.
